# Acdyon Flow - Frontend Challenge

A premium product homepage for the fictional Acdyon Flow tool, built entirely with React, Vite, and Tailwind CSS.

## Features
- Interactive deployment simulation state machine
- Semantic dark-mode UI with custom Tailwind properties
- Highly optimized for 390px (mobile) and 1440px (desktop)
- "rollback" easter egg

## Setup

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## Constraints Met
- No horizontal scrolling
- No fake numbers/testimonials
- Code is modular, semantic, and production-ready
- Reduced-motion safe
